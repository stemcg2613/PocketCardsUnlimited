# Pocket Cards Unlimited

Pocket Cards Unlimited is a web application I created for my Software Development Capstone project. It allows users to manage and organize their sports card collections.

## Features
- User registration and login
- Add, edit, view, and delete sports cards
- Search sports cards
- Track total cards and estimated collection value
- Security features to protect user accounts and collections

## Technologies Used
- C#
- ASP.NET Core MVC
- SQLite
- Entity Framework Core
- Visual Studio
